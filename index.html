「Webコンテンツ作成」の成果

本テーマについて

先行する情報工学の専門科目の基礎知識を応用して実践的な能力を修得することを目的にし、手順書を読み、実験を行い、レポートやプレゼンテーションにより報告するという実験の一連の流れを実践できるようになることやHTML等を用いたWebページ作成ができるようになることが目標である。

プロジェクト課題について

今回はNHKの番組を検索できるものを作成した。これはプルダウン式のボタンで、見たいチャンネルと番組のジャンルを指定し、検索ボタンを押すことでそれに関連している開始時間、終了時間、チャンネル、タイトル、サブタイトル、番組説明、出演者の計７項目を表示してくれる。押すごとに表示が変わるようになっていて番組が存在しない時は「検索結果0件」と表示するようになっている。NHKのロゴがあったり、検索結果がわかりやすいように枠で囲まれていたりする。

プロジェクト課題で作成したページ: project.html

数当てゲーム

最初に入力してもらうテキストボックスを作り、その次に回答ボタンを設置した。それぞれをJavaScriptで指定し、回答判定のメッセージを表示する場所を作り、そこも変数として指定した。関数の中は、まずゲームが終わっているかの判定をしてそこで終わっていたらこれ以上進まないようにした。その後まず回数を増やし、1からスタートになり、次にテキストのデータを取得し、それを数字に直した。判定の部分ではまず正解かどうかを判定し、もし正解だったらゲームを終わらすための関数をtrueにした。そして3回目の時のみ特殊な表示になるのでそこを先に書き、最後に1,2回目の答えより大きいか小さいかを判定させた。最後にボタンを押す処理を書いて完成した。

数当てゲームのページ: kazuate.html

各授業回の学習事項

  • 第一回 WWW と HTML

    Webページを構成しているのはHTML、CSS、JavaScript、画像・音声・動画がほとんどとなっている。HTMLではブロック要素とインライン要素と言われるものを使い文書をWebページに書くことができる。それらは膨大な種類があり、それぞれの要素を使うことで文章を見やすくしたり、デコレーションしたりすることができる。これらの要素は<p>のようにすることで始まり、終わりには</p>とすることで完成する。属性というものがあり、これはそれらの要素に追加でさまざまなものをつけることができる。例えば画像を表示することや、ハイパーリンクをつけることなどができる。また、HTMLは間違いに気づくことが難しいものなのでページのソースを見るほかに、HTML バリデーションを使うなどしてコードの修正をしていくのが良い。

    演習の成果: 演習1-4: HTMLのさまざまな要素

  • 第2回 CSS による Web ページの装飾

    CSSではHTMLで作った文に装飾を施すことができる。色を変えたり、写真の位置をずらしたりハイパーリンクの設定を変えたりすることができる。CSSの書式ではセレクタというもので要素を指定し、したい操作のことをプロパティ、そしてその値のことをプロパティ値という。とある要素のみを装飾したい場合に必要となってくるのがclassでclassを設定することでそのもの単体を選ぶことができる。

    演習の成果: 演習2-3: さまざまなwebブラウザ

  • 第3回 JavaScript の基本

    JavaScriptは、インタプリタ言語でコンパイルを必要としない言語である。そのため、間違いに気づきにくかったりする時がある。Webページのコンソールで簡単に続行することができ、確認も簡単である。Javaと少し文法が違い、型を全てletで表すことができる。間違った式を計算すると、NaNとなり、数値ではないと示してくれる。undefinedやnullはそれぞれ未定義、空っぽを意味しており、その値を使って条件式を書くこともできる。グローバル関数とローカル関数があり、グローバル関数はページが開かれている間ずっと使われているものでローカル関数は関数が使われている間だけのものとなっていて、あんまりグローバル関数を多用しない方が良い。

    演習の成果: 演習3-6: JavaScriptのオブジェクト

  • 第4回 DOM と JavaScript

    DOMとはDocument Object Modelの略称で、HTMLの検索方法とテキスト変更方法のことである。Input要素のtype属性は入力する値の種類を指定するもので、色や、日付、ファイル名など様々なものがある。Java Scriptのdocument.querySelectorを使うことでそれぞれの要素を選択し、valueなどで要素を参照する。イベントハンドラとはイベントが発生した時に実行する処理のことでfunctionを使うことでその時専用の処理が行われる。

    演習の成果: 演習4-10: 足し算ページ

  • 第5回 イベント処理

    createElement()で、要素を新しく作り、.insertAdjacentElement()で要素を配置することができる。他にも.remove()で要素を削除し、.setAttribute()でハイパーリンクや写真などの属性を付与することができる。

    演習の成果: 演習5-7: DOMを操作するJSプログラム

工夫点，苦心点，強調点，感想

今までHTMLに少し触れたことがある程度でCSSやJavaScriptのことはあまり触れてきていなかったので、少し難しく感じました。ですが、全ていい感じに完成することができたので良かったです。CSSはまだまだ自分が知らない色々な装飾方法があると思うので今後も少しずつ触れて多様な装飾をつけることができるようにしていきたいです。HTMLは久しぶりに触ったので思っていたより覚えていなかったのでいい復習になりました。特にJavaScriptがJavaとごちゃ混ぜになったり、letと定義するのを忘れていたりしたので、難しかったです。JavaScriptでは習ったばかりのメソッドをたくさん使ったのでとても刺激になりました。通信をするのは初めてだったのでこんな感じにするのだなあと思いました。 プロジェクト課題では、ボタンをプルダウン形式にしたので、値とメモリの設定をするのが大変でした。ページに無かったボタンだったので、MDNWebDocsを見ながら追加しました。結果として一番直感的で分かりやすいボタンになったと思います。 一度作った後にEテレの時にうまいこと動作しないことに気づいたので、data.listを変数に入れ、その長さを取ることでNHK 総合、Eテレどちらも対応するようにしました。そうすると今度はデータがないときにエラーとなってしまったのでそこも初期値をnullにし、データがなかった時や、リストの長さが0の時にその時専用の表示をするようにしました。 元々のデータから検索結果に必要なものを取り出すのは単純な作業でしたが、故に大変な部分でもありました。データの名前が違ったことで出てこない要素が生じたり、同い表示のものが２個あったりなどの事態がおきました。そこはもう少し綺麗にまとめられたら良かったなと思いました。 古いものを消して新しいものを上書きするのは何かいいメソッドがないかなと調べたところremove()という要素を消すメソッドを発見したので、あらかじめresultをoldに指定しておき、nullじゃないときにremove()で全てを消し去るようにして、また要素を追加するようにしました。 今回の学習を通して私は、ホームページを作る方法を学ぶことができました。JavaScriptや、HTML、CSSを使うことで比較的簡単にWebサイトを作成することができるのでこの先、私がアプリなどを作った時はWebサイトも同時に作り、宣伝に活用していきたいと思います。
